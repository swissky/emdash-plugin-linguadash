Requires EmDash 0.42 or later with a plugin sandbox runner, and Astro i18n routing with every target language listed in `i18n.locales`. Machine translation also needs `EMDASH_ENCRYPTION_KEY`.

1. Select **Install**.
2. Open **Translations** in the admin, then **Translation settings**, and enter the target languages, e.g. `fr, it, en`.
3. In **Content Types**, switch on **Translatable** for every field that differs per language.
4. Optional: pick a machine translation provider, enter its credentials and select **Test machine translation**.
